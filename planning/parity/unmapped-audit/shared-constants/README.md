# Row 6 · `qcsrc/common/constants.qh`

Audited against Xonotic data `863cd3e8456e18f577f7fe5fef857ff55ae62cc0` in the local checkout. The native paths keep the explicit player lifecycle and native protocol from ADR-0007 and ADR-0011.

| Family | Consumer and outcome |
| --- | --- |
| `FRAGS_*` | Xonotic uses frag sentinels for observer and out-of-game participation in `server/client.qc`, `ent_cs.qh` and round rules. Native `ClientManager` and gametype participation state use explicit player state. |
| `CVAR_*` | The three names in this header have no consumers at the pin. Native `CvarService` uses `CvarFlags` for persistence, notifications and readonly writes. |
| `SERVERFLAG_*` | Native `GameWorld.ReadLevelCvars`, `ClientInit`, `NightVisionOverlay` and `PickupPanel` carry the fullbright permission and pickup-timer restriction. Teamplay uses the native gametype state. `ServerListInfo` still decodes the playerstats flags. This audit used no stats endpoints. |
| `SPECIES_*` | Xonotic resolves the final model and skin, defaults to skin 0 when the requested sidecar is missing, and copies species to body clones. `Damage_DamageInfo` carries it for attached bleed, and `Violence_GibSplash_At` sends it for gibs. Native attached damage already resolves species at its receiver. The server now resolves species at spawn and after bot appearance selection, and copies it to clones. The native world-space damage puff uses the shipped alien or robot blood effect where available. Native model gibs select the flesh skin or robot fragments, with the shiny robot skin. |
| `RANKINGS_CNT`, `KEY_*`, `HUD_*` | Native `RaceRecords` caps persistent rankings at 99. `PressedKeyBits` feeds dodging and pressed-key indicators. Vehicle state drives the native Bumblebee gunner HUD and ordinary on-foot view. |
| `MAPVOTE_COUNT`, `GTV_*` | Native map and gametype ballot builders now share a 20-entry cap. With abstain enabled, `Start` reserves one slot under the cap and still honors a lower configured map count. Native gametype aliases resolve through `sv_vote_gametype_<name>_type`; `MapVoteCandidate.Available` drives availability instead of the QC bit field. The base-map support filter remains a separate gap. |
| Player hulls and `PL_CORPSE_SCALE` | Standing and crouch use the established `-16 -16 -24` mins and max Z 45 or 25. `GameWorld.OnEndFrame` now applies the original corpse formula once after same-tick damage, relinks the body, and leaves respawn to restore the live hull. Default corpse max Z is 5.0 standing or 0.3 crouched. The original CSQC client also computes standing dead bounds. Native dead movement prediction returns early, so the check covers authoritative collision and hit traces. |
| Engine `FL_*`, game entity flags | `EntFlags` retains the native collision, movement and cheat bits. Native gameplay uses explicit state such as projectile kind, `CanPickupItems`, crouch, and movement slick state for the game bits. Those states feed trigger admission, item touch, movement and prediction. |
| `INITPRIO_*` | Original `FINDTARGET` (10) precedes `DROPTOFLOOR` (20), `SETLOCATION` (90), `LINKDOORS` (91) and `LAST` (99). Native map boot now resolves queued targets before placing and linking start-open doors. Gametype selection still precedes spawning so spawn functions can query the mode. Item-team setup, floor drops, gametype graphs and `target_spawn` use separate native phases. This check establishes door-relative ordering only. |
| `EF_SHOCK`, `EFMASK_CHEAP` | Stunned status sets and clears 262144, and `CsqcModelEffects` reads it for the actor aura. Xonotic filters the copied owner or spectatee flags on exterior weapons, carried buffs, spectators and viewmodels. Native uses separate consumers for weapon alpha and glow, the carried relic, spectator state, and viewmodel draw and depth. Those consumers do not copy expensive actor aura bits. Native viewmodel depth and no-shadow behavior already have dedicated implementations. Full inherited cheap render-flag behavior has no general native equivalent and was not verified. |

The local pinned server printed Gak's species as 2 and changed a standing edict's max Z from 45 to 5 after its normal kill command. Native integration tests checked that a non-gibbed corpse keeps its live hitbox before the end-of-tick update, loses a trace hit above the reduced hull, remains hittable in the reduced hull and respawns at standing size. They also checked a missing-skin species fallback, clone ownership, by-name event encoding, the map ballot cap and the closed-door target pose during map boot. [Evidence](evidence.txt)

The Godot Compatibility fixture exercised native gib dispatch with real mounted assets. The pin's stock player sidecars include human and alien examples. The robot example exercised the native loader with a modeled species value. The fixture verified alien skull skin 2 and shiny robot skull skin 1. Species-specific gib trails, splat and bloodshower particles, the additional shiny colormod, gentle modes and remote playback remain outside that evidence. The native world puff is a native addition. Its species choice reuses shipped particles, and animal or reserved species keep the native generic fallback because the shipped catalog lacks those blood names. [Evidence](evidence.txt)
